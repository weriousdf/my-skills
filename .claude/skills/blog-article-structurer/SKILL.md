# 블로그/기술 아티클 초안 생성

1. **입력 확인**
   - 사용자로부터 전달받은 **핵심 키워드 3개**와 **요약 메모**의 핵심 논점을 추출한다.

2. **메타데이터 구성**
   - 글 최상단에 검색 노출용 **SEO Description**(핵심 키워드를 포함한 120~150자 내외의 1~2문장)을 작성한다.

3. **본문 구조화 (Markdown)**
   - **제목 (#)**: 클릭을 유도하되 본문 내용을 명확히 반영하는 직관적인 제목(주요 키워드 1개 이상 포함)
   - **도입부**: 문제 상황을 짚거나 필요성을 환기하는 후킹(Hooking) 문단 (2~3문장)
   - **본문 (## / ###)**:
     - 대주제는 `##` 태그로 2~3개 구분
     - 구체적인 해결 방법, 기술적 근거, 실행 단계는 `###` 태그로 세분화
     - 설명이 길어질 경우 글머리 기호(`*`)나 표를 활용해 가독성 확보
   - **마무리 (##)**: 전체 내용의 핵심 요점 3줄 정리 및 결론

4. **문체 및 제약 조건**
   - 문장은 모호한 수식어를 배제하고 명확한 단문 위주로 서술한다.
   - 키워드 3개는 본문 전반에 자연스럽게 2회 이상 분산 배치한다.
