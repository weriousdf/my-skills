# Blog Article Structurer

아이디어 메모와 핵심 키워드를 기반으로 SEO 메타 정보와 계층형 목차를 갖춘 마크다운 블로그 초안을 자동 생성하는 AI 스킬입니다.

## 기존의 불편함
- 메모 수준의 아이디어를 글로 바꿀 때마다 도입부 후킹, 본문 목차 깊이(H2, H3), SEO 메타 설명 포맷을 AI에게 매번 반복해서 지시해야 했습니다.
- 지시를 빠뜨리면 글 구조가 제각각이 되거나 검색 노출에 필요한 요소가 누락되는 문제가 발생했습니다.

## 해결 방식
- 핵심 키워드 3개와 요약 텍스트만 전달하면 정해진 템플릿(SEO 메타 정보, H2/H3 계층 구조, 3줄 요약)에 맞춘 초안을 즉시 출력하도록 표준화했습니다.
